# Deed to Map — support site

Support, privacy policy and terms of use for the iOS app
**Deed to Map: Metes & Bounds**.

Published with GitHub Pages.

| Page | Path | Use in App Store Connect as |
|---|---|---|
| Support | `/` | Support URL |
| Privacy | `/privacy` | Privacy Policy URL |
| Terms | `/terms` | License Agreement / EULA link |

## Setup

1. Create a public repository named `deed-to-map-support`.
2. Add `index.md`, `privacy.md`, `terms.md`, `_config.yml`.
3. Settings → Pages → Source: Deploy from a branch → `main` / `root`.
4. Wait a minute, then check all three URLs.

If the clean URLs do not work, your existing site may not use Jekyll
permalinks. In that case copy the layout of the satellite-tracker-support
repository and paste these bodies into it.

## Before publishing

- Confirm the support email is the one you want shown.
- Set the effective date on `privacy.md` and `terms.md` to your release date.
- Re-read section 10 of the terms if you are not filing from Armenia.
